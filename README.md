# Order-Management-System
Order management system including a mobile flutter application and ASP.NET Core web application for Katliey Graphics Solutions

We as NexGen Solutions partnering with Katliey Graphics Solution in order to solve their current problem they are facing within their day to day business operations

We have discovered that the is a problem of some or many orders not being able to be tracked correctly which sometimes leads to some orders not being done and which causes loss of profit and causes untrust to customers

The solution we proposed is to create a flutter mobile application which will be able to help customers place orders at the comfort of their homes annd with ease, and an ASP.NET Core Web application which will be used by the manager or the staff of our stakeholder company to e able to manage orders within the system to make it more efficient and the business opertions to work smoothly
